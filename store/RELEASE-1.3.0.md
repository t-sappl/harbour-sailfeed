# GitHub release text – Sailfeed 1.3.0

Tag `v1.3.0`, title "Sailfeed 1.3.0". Paste everything below the line into the release description and attach the RPMs (aarch64, armv7hl, i486).

---

### New
- **Share target** – share a page from the browser (or text with a web address) to **"Sailfeed – Subscribe to website"**. Sailfeed comes to the front, or starts if it was closed, and finds the site's feeds.

### Subscribe to website
- Feeds that carry the same articles as one you already subscribe to are marked **"Probably already subscribed as …"** – also when the address or the name differs (e.g. engadget.com/feed and engadget.com/rss.xml).
- An address copied without `https://` (e.g. `engadget.com`) is taken from the clipboard.

### Reading
- Short articles (e.g. OSnews link posts with a quote and one sentence) are shown in reader mode instead of the site's footer.

### Other
- German: the swipe tip uses the same "du" form as the other tips.

### Install
Through OpenRepos / Storeman, or download the RPM for your device below (aarch64 for current devices such as the Jolla Phone (2026), armv7hl for older 32-bit devices, i486 for the emulator and Intel tablets). Sailfeed needs a Nextcloud server with the **News** app.
