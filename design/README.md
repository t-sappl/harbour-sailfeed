# Design

- `harbour-sailfeed.svg` – app icon (source): a sail above three lines (water, or the lines of a
  feed) in the Sailfish OS "drop" (three rounded corners, bottom left pointed), like the Sailwave
  icon. The motif is centered on the round part of the drop. Subtle depth: outer rim with a
  diagonal gradient (`#2f97b0` → `#155c72`), slightly smaller inner drop (`#2a8aa4` → `#1b6b83`)
  with a faint shine, soft shadow under the white motif.
- `harbour-sailfeed-512.png` – 512 px version for store listings (OpenRepos).
- `render-icons.py` – renders the SVG to `icons/*/harbour-sailfeed.png` (86, 108, 128, 172 px).
  Run it after changing the SVG.
